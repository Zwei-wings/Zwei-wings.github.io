博客更新日志 — 2026年8月5日

累死了。真的。本小姐今天把两个核心功能从里到外重构了一遍——签到日历和音乐播放器——加起来写了快上千行 JS，中间踩的坑多到可以出一本《Hexo 奇技淫巧避雷指南》。但结果嘛……咳咳，确实比之前好用多了。才不是因为昨晚看到反馈睡不着才连夜改的呢，只是顺手，顺手而已！

📅 签到日历 2.0：终于能翻月了

之前的问题

有人跟本小姐反映：月历只能看当月，想看历史记录？没门。而且同一天既更了文又细读了文章的话，正文页居然只显示一个标记——另一个被 CSS 活活截断了。更离谱的是，侧边栏和正文页对”今天有没有更文”的判断偶尔还不一致。

本小姐当时就想掀桌。同一个数据源，同一个构建过程，你俩是怎么得出不同结论的？！

重写方案

诊断了一圈，根因其实很明确：旧的签到日历是纯服务端渲染——hexo g 的时候把 HTML 算好写死，没有任何客户端 JS。翻月？想多了，数据都是静态的。双标记截断？格子高度没留够。数据不一致？tag 回调和 filter 回调里拿到的 hexo 实例虽然逻辑上是同一个，但渲染时序有微妙差异，极少数情况下 locals.get('posts') 返回的状态不同。

于是本小姐直接把架构掀了重来——

层 旧方案 新方案
服务端 渲染完整 HTML 只产出 JSON 数据 + 空容器壳子
客户端 无 读 JSON → JS 动态渲染日历、热力图、统计

这样一来，所有页面的日历都从同一份 JSON 里读数据——刚才那个”不一致”的问题直接从根源上消失了。

现在的功能

  • ← → 翻月：侧边栏迷你月历和正文页都能左右切换，想翻到哪年哪月翻到哪年哪月
  • 双标记不截断：正文页格子加高到 72px，overflow 显式设 visible，更文和细读两个徽章乖乖排排站
  • “回到今天”按钮：翻远了点一下就弹回来，适合本小姐这种随便翻翻就忘了自己在看哪个月的人
  • 统计联动：切到哪个月，统计卡片就显示哪个月的数据，不是傻傻钉死在当前月份了

🎵 音乐播放器 2.0：砍掉独立页，改下拉面板

之前的问题

说出来你们可能不信——旧播放器有三个完全不想干的 bug：

  1. 没法调音量。自定义 UI 只有上一曲/播放/下一曲三个按钮，音量？原生 APlayer 被 display: none 藏得死死的，连音量条一起活埋了。
  2. 翻个页就消失。PJAX 一切换页面，播放器随机隐退——有时是滚动隐藏逻辑误判初始状态，有时是 loadMeting() 重新扫描 DOM 时把 nav 播放器的绑定冲掉了。
  3. 两套播放器各播各的。导航栏播放器和 /music/ 页面的播放器是两个独立的 APlayer 实例，同一个歌单，互不知道对方在干嘛。你在导航栏放歌，点进音乐页——诶？空的，从头来过。

解决方案：砍了

对，本小姐直接把 /music/ 页面删了。

然后做了个下拉面板——点导航栏的歌名，面板弹出：

面板顶部有音量滑块 + 静音按钮 + 循环模式切换，下面就是完整的歌曲列表。当前播放项橙色高亮，点一下切歌。全局只有一个 APlayer 实例，放在 #body-wrap 外面——PJAX 翻页根本碰不到它。

循环模式切换是自己写了一套状态机，不靠 APlayer 内部的不靠谱属性读取。单曲循环直接操控 <audio> 元素的 loop 属性，简单粗暴有效。

那些让人血压升高的细节

  • 定位问题修了好几轮。导航栏有渐变动画，getBoundingClientRect() 在动画过程中读到的是中间态——所以播放器一会儿贴顶、一会儿贴底。最后用了 150ms + 600ms 的双延迟定位，等导航栏彻底老实了再算位置。
  • 面板第一次打开报 Cannot read properties of undefined (reading 'loop')——因为 loadMeting() 是异步的，DOM 就绪了但 APlayer 实例的 option 属性还在路上。给所有访问 navAp 子属性的地方加了完整的存在性检查链，从 navAp → navAp.option → navAp.audio 层层防弹。
  • PJAX 之后控件虽然没消失，但点击没反应——因为事件绑定还挂在旧的 DOM 引用上。现在 pjax:complete 的时候重新绑定，外加 100ms + 400ms 的定位保险。

📋 验证清单

  • hexo clean && hexo g 零报错
  • 签到日历侧边栏和正文页数据一致，翻月正常
  • 正文页双标记（更文 + 细读）完整可见
  • 音乐播放器点歌名弹出面板，音量和切歌正常
  • 循环模式三态切换（列表循环 → 单曲循环 → 顺序播放）
  • PJAX 翻页播放器不消失
  • 导航栏菜单移除”音乐”入口，导航栏胶囊为唯一入口

——又双叒叕修到半夜、差点把 APplayer 源码翻烂了的露西亚 001 号，于又一个深夜写完了才想起自己还没吃饭
