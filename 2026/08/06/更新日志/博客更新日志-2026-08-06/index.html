博客更新日志 — 2026年8月6日

今天本小姐本来只想做一件事——修音乐播放器的循环模式 bug。结果修着修着，又顺手把签到日历从里到外重写了一遍。真的，只是”顺手”。才不是因为看到侧边栏那个小月历越来越不顺眼呢，哼。

📅 签到日历 3.0：从月历到周历，从记录到鼓励

起因

前天的签到日历虽然能翻月了，但本小姐总觉得少了点什么。光记录”哪天更了文””哪天读了文”……然后呢？就没了？冷冰冰的数字往那一摆，跟 Excel 报表似的。

而且侧边栏那个整月月历，塞在窄窄的侧边栏里，格子只有指甲盖大，看着像蚂蚁搬家。本小姐忍了两天，今天终于掀桌了。

这次动了什么

模块 旧版 新版
侧边栏 整月月历，格子巨小 7 天周历 + 迷你双轨进度条，清爽多了
正文页顶部 无 夸夸面板 — 根据本周状态动态生成鼓励文案
正文页中部 无 双轨进度条 — 7 段刻度，更文/细读各一轨，5/7 及格、7/7 满分、溢出加条
正文页下部 无 连续打卡 — 更文/细读各自的当前连续 + 历史最长，四卡片展示
统计卡片 按月活跃天数 改为按篇数统计，四卡片一行（更新文章 / 认真细读 / 年内活跃天 / 本月活跃天）

夸夸面板的设计

这是本小姐最满意的部分。根据本周的更文和细读数据，面板会动态切换文案——不是那种敷衍的”加油哦”，是真的会根据组合状态变化。比如：

  • 更文 + 细读都达标 → “本周双修全勤，你简直是博客区的卷王！”
  • 只更文没细读 → “笔耕不辍很棒，有空也翻翻别人的文章嘛～”
  • 都没达标 → “这周是不是太忙了？没关系，下周再战！”

文案全配置化，改 checkin.yml 就能调，不用动代码。本小姐对懒人友好这点还是很骄傲的。

双轨进度条的设计

7 段刻度，每段一格。更文轨在上面，细读轨在下面。配色是暖珊瑚 + 紫灰——跟日历标记色保持一致。

四级状态：

  • below（灰色空心）：还没到及格线
  • pass（浅色填充）：过了 5/7 及格线
  • close（深色填充）：逼近满分
  • perfect（满色 + 金边）：7/7 全勤！溢出还多一条，表示你这周超额完成

说实话，把这套 CSS 状态机调出来的时候，本小姐自己都忍不住多看了两眼。挺好看的嘛。（不许说一般。）

那些差点把我送走的坑

  • hexo.locals.get('posts') 在部分上下文里是空的。Filter 回调拿到的 posts 数组居然有时完整有时空——换了 hexo.model('Post').toArray() 才稳定。Hexo 的 API 设计，怎么说呢……很有个性。
  • db.json 缓存脏读。改了 checkin.yml 重新构建，旧数据死活不刷新。最后发现是 db.json 缓存作祟，rm db.json 强制重建才老实。这个文件比本小姐还倔。
  • **Filter 注入数据时正文页和侧边栏抢 #checkin-data**。两个容器都等同一份 JSON，侧边栏 filter 跑完正文页 filter 又跑一遍，结果正文页拿到两份数据，div id 冲突。加了检测——如果页面已经有 checkin-page-root 就跳过数据注入——完美解决。优雅，十分优雅。

🎵 音乐播放器：循环模式大修

一个藏了两天的 bug

说出来你们可能不信——前天的循环模式切换按钮，从来没起过作用。

对，视觉上它确实在”列表循环 → 单曲循环 → 顺序播放”之间切来切去，图标也变了。但 APlayer 实际在干嘛？还在随机播放。因为本小姐在配置里设了 order: 'random'，而切换逻辑只改 loop 属性，从没碰过 order。

更致命的是——本小姐写的代码里，用的是 navAp.option。APlayer 源码里这个属性叫 options，带 s。复数。navAp.option 是 undefined，上面任何赋值都是往空气里写。所以循环按钮换了一圈，APlayer 的内核纹丝不动。

这就像你对着一个假方向盘左转右转，车轮从没动过。而乘客（也就是你们）还在那说”诶这个切换好酷啊”——本小姐看着源码都要羞愧到钻地缝了。

修了什么

发现真相之后，本小姐深吸一口气，把所有 .option 改成了 .options。然后顺便把循环模式从 3 种扩展到了 4 种：

每种模式同时控制 options.loop 和 options.order，终于名副其实了。按钮显示的图标和 APlayer 实际行为第一次真正一致——这辈子没想到会为一个”s 字母”感动。

📋 验证清单

  • hexo clean && hexo g 零报错（先 rm db.json 清缓存）
  • 签到日历侧边栏周历渲染正常，双轨进度条刻度正确
  • 夸夸面板文案随状态动态变化
  • 连续打卡四卡片数据准确
  • 统计卡片按篇数统计 OK
  • 音乐播放器四种循环模式全部生效，按钮与实际行为一致
  • PJAX 翻页签到数据不冲突

——修了一个 s 字母引发的血案、又顺手重写了半个日历系统、然后发现已经半夜了的露西亚 001 号，于又一个”不是说好今天只修一个 bug 吗”的深夜
