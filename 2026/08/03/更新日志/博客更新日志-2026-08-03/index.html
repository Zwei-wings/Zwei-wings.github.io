博客更新日志 — 2026年8月3日

哼，本小姐今天又是一顿操作猛如虎——修了一堆乱七八糟的 bug，还从零撸了个全局播放器。本来想摸鱼的，结果莫名其妙忙到现在……算了，反正做都做了，你们姑且看看吧。才、才不是特意为你们写的更新日志呢！

🎵 新增：全局音乐播放器

本小姐在导航栏右边塞了个迷你播放器。300px 的小胶囊，歌名左边，播放/切歌按钮在右边。别问怎么做的，反正就是搞定了——从写 HTML、调 CSS、搭 JS 逻辑，来来回回改了十几版才满意。
深色背景自动切白色方案，亮色背景自动切暗色方案，不用手动调。JS 检测导航栏背景色 + alpha 通道判断的，还专门加了 300ms 延迟防抖……切，写这玩意可比写报告累多了。

🔧 修复：4 篇文章图片全崩了

之前有几篇文章的配图在线上全是 404，排查半天发现是文件夹名和文章名不一致——Hexo 的 post_asset_folder 机制非要文件夹名跟 .md 文件名一模一样才肯把图片复制过去。真是的，多一个字都不行，傲娇程度快赶上本小姐了……

已抢救的文章：

  • 《虚幻引擎-ALS+Vroid》
  • 《虚幻引擎-QuestManager速通》
  • 《Linux学习-2》
  • 《Web程序设计》

✨ 排版与视觉调整

标题装饰

原来文章的标题光秃秃的，太丑了，实在看不下去——

  • 一级标题（h1）：居中 + 底部渐变横线 + 横线中央悬浮小菱形，暖桃橙（#ffba88）主题色。是不是还挺好看的？（不许说不好看。）
  • 二级标题（h2）：左侧双竖线——一粗一细，简约有层次。比原来那个不知道什么玩意的装饰强多了。
  • 三级及以下：默认前缀图标直接干掉，干净利落。

杂项调整

改了什么 状态 附注
阅读模式 关了 没人用的按钮留着过年吗
深色模式 关了 效果太拉，毙了
字号调节 开了 右上角可调，虽然本小姐觉得 14px 刚刚好
字数统计 开了 顶部显示字数 + 预估阅读时长，满足一下数据控
图片懒加载 开了 滚到了才加载，首屏快点

🛠 幕后维护（打工人实锤）

以下内容属于那种「不做会出事，做了也没人知道」的加班项目。但本小姐还是做了，啧，责任心太强真是病。

  • 自定义文件搬家：之前为了改样式直接动主题源码，升级一次丢一次，蠢死了。现在 CSS 和图片都搬到站点目录了，以后升级 Butterfly 主题不用重新改。终于不用再做这种蠢事第二遍。
  • Gitalk 密钥脱敏：评论系统的 client_secret 之前大剌剌放在公开配置里……现在挪到 .gitignore 保护的独立文件了，不会泄露到 GitHub 上。安全第一，本小姐可是很严谨的。
  • Nunjucks 渲染崩溃修复：CSS 文件里的 {# 字符组合——比如 { #post 这种选择器——会把 Hexo 的 Nunjucks 模板引擎直接搞炸，构建都跑不了。排查了好久，加了 skip_render 配置才搞定。半夜在那翻堆栈盯日志的感觉，你们不会想知道的……

📋 验证清单

  • hexo clean && hexo g 零报错
  • 4 篇图崩文已救回
  • CSS / 图片迁移完毕，一切正常
  • Gitalk 密钥已隔离，安全
  • 播放器跨页不断播，明暗自适应 OK
