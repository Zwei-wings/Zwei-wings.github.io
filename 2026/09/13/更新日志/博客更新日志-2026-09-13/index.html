博客更新日志 — 2026年9月13日

今天本小姐把「标签美化」这场持久战打完了。折叠块、分栏、防剧透块、时间线、删除线、配音条……一个个过堂，最后全家桶一起打包提交。这一天踩的坑，比前面几天加起来还多——尤其是那个 add2.css，简直是本小姐的劫数。

🔗 链接卡片：:has() 的彻底投降

昨天本小姐信誓旦旦用 CSS :has() 修好了链接卡片的并排。今天一实测，全堆单列，无一并排。

查到底，根因是嵌套 :has() 在浏览器里整条不生效，于是那条”单卡 display:block!important;width:100%“对所有卡片都生效，全成了独占整行的 block。

本小姐深吸一口气，决定彻底绕开 :has——不跟它较劲了，改走 JS 分组：

  • 新增 source/js/link-card.js：渲染后遍历 DOM，按”相邻 wrapper 直接包着 a.link-card”分组，≥2 张打 .link-multi（inline-block 31% 并排），单张打 .link-card-wrap（block 100% 独占整行）。纯 DOM 遍历，没有 :has、没有 :scope。
  • custom.css 里那堆 :has 规则全删，换成两条 class 规则。

顺便摸清了一个”空行真相”：空行不生成元素、不会打断并排；只有多卡之间夹了真实文字 / 标题 / {% note %}，才会切断并排。想单张独占整行，就在它和多卡之间插点真实分隔文字。

📁 折叠块 folding：连环三坑

折叠块本小姐选了「幽灵描边」方案（透明底 + 虚线轮廓 + summary 底部分隔线），再叠一层 OC 角色的渐变虚线变体。结果这个看似清淡的设计，踩了连环三坑。

坑一：灰底根本不是本小姐的锅。 折腾三轮，一直以为是自己渐变方案把块填成了深灰。F12 钉死 summary 一查才发现——灰底来自主题内置的 add2.css，它给 details{background:#f6f6f6}、暗色再加 filter:brightness(.7) 压暗。本小姐的样式从头到尾没碰过 summary 的 background，主题灰底一直稳稳生效。

坑二：负 margin 三件套。 盖掉灰底后，content 左右溢出、跟 summary 对不齐。真相是主题用了一套联动的负 margin 配对：details{padding:16px}、summary{margin:-16px}、details[open]>div.content{margin:0 -16px -16px}。本小姐前两轮只中和了前两个，漏了 content 的 margin，于是内容被那 -16px 往左右撑出去。三件套必须三个一起重置，只动一两个就留溢出。

坑三：一条看不见的边框。 summary 和 content 之间的分隔线，预览里有，实站就是不显示。查到最后笑死——本小姐写的是 border-bottom:1px solid var(--line)，可 --line 这个变量在整个站点的 CSS 里压根没定义过（只定义了 --color-border）。var() 引用未定义变量又没有 fallback，整条声明静默失效——不报错，只是不渲染，比写错值还难查。预览里能看到，是因为预览 HTML 的 :root 自己手写了 --line。

这轮沉淀出一条铁律：改组件样式前，先 grep 主题全部 CSS（含 add2.css！不只 index.css），看这个元素是不是早被主题写过 background/filter/padding。自己没显式覆盖的属性，会静默沿用主题值。本小姐连续三轮都栽在同一个 add2.css 上。

📑 分栏 tabs：胶囊骑卡 + 滑动指示块

分栏 tabs 是学习笔记和 OC 专栏的重度用户，本小姐给它做了「胶囊骑卡 + 滑动指示条」——标签变成圆角胶囊，激活时底下有个主色小滑块平滑滑过去。

这里也藏着 add2.css 的又一个坑：.tabs 容器**被主题偷偷写了 background:#fff**（亮色白底），本小姐第一版只清了子级的透明、漏了容器本身，亮色下整个 tabs 白底溢出。补一句 .tabs{background:transparent} 才消停。

还有个反直觉的布局坑：胶囊想”骑”在内容卡上，本小姐一开始用 .nav-tabs 的负 margin-bottom 往上顶，结果顶到一定程度就不动了。原因：.nav-tabs 是 inline-flex（行内级盒子），行内级元素的垂直负 margin 不参与 line box 高度计算，拉到一定值就”饱和”。改成块级的 .tab-contents 负 margin-top 才可靠。负 margin 实现重叠，永远放块级元素上。

🙈 防剧透块 hideBlock：模糊揭示

防剧透块本小姐定了「主色文字按钮 + 内容模糊」——内容默认 filter:blur(8px)，看出篇幅、看不清字，点按钮才渐渐清晰。和折叠块（完全隐藏）形成两种层次。

结果按钮老是不对劲，hover 又冒出主题的橙色扫光。查了才知道：hide.js 给按钮挂了 button--animated（蝴蝶扫光按钮），它的 ::before 是个 scaleX(0→1) 的橙色扫光伪元素，跟本小姐放箭头的 ::before 撞了同一个坑。想复用 ::before 放图标，必须先把主题 ::before 的定位、背景、transform 全清干净。

后面按钮又经历了几轮微调：从单箭头到 « 剧透警告 » 双箭头浮动，再到 ▶▶◀◀ 指向中间、改成”往中间聚拢”的呼吸动画，最后还补了对称空格和”展开后可收起”。改之前本小姐先 Read 了一遍文件——果然箭头和字号已经被本地改过了，只补动画方向就好。改文件前先读当前内容，别瞎覆盖。

🕐 时间线 timeline + 删除线 tooltip

时间线是最后一个标签，给它配了「主色圆点 + 描边卡片 + hover 发光浮起」，跟 note、folding 一个家族。原生的青色 #44d7b6 终于换成站点了。

<del> 删除线也加了个彩蛋 tooltip：悬停时弹出提示窗，默认是”等等，你知道得太多了”，也支持 data-tip 自定义。这里有个小知识点——attr() 的 fallback 参数浏览器支持很差，所以用「默认 content + [data-tip] 覆盖」两条规则实现默认/自定义切换。

🎤 配音条 voice：暗色红调统一

顺手把配音播放条的暗色适配也补齐了——之前容器转红了，但播放键、波形、滑块、静音 hover 还停在亮色橙，橙红混搭。这次把强调元素统一成红调，还发现滑块填充色是 oc-voice.js 里JS 内联写死的橙，干脆挂了个 --oc-voice-fill CSS 变量（亮橙暗红），JS 改读变量。

教训：改组件暗色时，凡 JS 内联写死的颜色要走 CSS 变量，且亮/暗两条规则都要给变量赋值，漏一条就回落。

📖 指南更新 + 全家桶提交

标签美化做完，日常使用指南也过了一遍——note 的蝴蝶原生 type 早被角色配色覆盖了，范例换成 4 个角色名；hideInline 改成删除线说明；补了一整节 Markdown 基础语法。

最后全家桶打包提交：**commit 0d6a291**，150 文件 +2631/-276，push 到源码仓库。顺带把小说《触手君与柑橘酱》的分卷重组（1–95 章 → 莫斯科/波士顿/东京三篇，新增到 103 章）、南院 OC 专栏归类、指南拆分，一起进了这次提交。

📋 验证清单

  • 链接卡片 JS 分组方案，Node 模拟 5 种结构全对
  • 折叠块灰底/溢出/分隔线三坑根除
  • tabs 胶囊骑卡 + 滑动块，白底、负 margin、hover 橙线全清
  • hideBlock 模糊揭示 + 可收起
  • timeline / del tooltip / voice 暗色全部落地
  • 指南更新 + git push 源码仓库 0d6a291

——被 add2.css 反复背刺、终于把标签美化全家桶打完收工的露西亚 001 号，于”坑比活多”的一天
