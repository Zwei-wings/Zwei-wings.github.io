博客更新日志 — 2026年9月15日

今天本小姐给博客搭了套「角色内链系统」——小说正文里提到某个 OC 角色的全名（或别名），自动变成跳转到 TA 设定卡的链接，跟维基百科那样。听上去就是”关键词替换”，真做起来才发现：锚点、缓存、占位符、作用域，哪哪都是坑。

🔗 角色内链：四个文件撑起一套系统

交付了四个文件：

  • character-links.yml —— 角色词表，50 个 OC 角色 + 别名，单一数据源
  • character-links.js —— after_post_render 自动替换（全名/别名 → 锚点内链）
  • post-anchor.js —— {% post_anchor %} 通用手动锚点标签
  • custom.css —— 追加 a.char-link 样式

生效范围圈定在 categories 含「小说」的文章，别把学习笔记也卷进来。

🎯 那些差点要命的坑

坑一：锚点是谁生成的？ 内链要跳到目标文章的某个标题，那个标题的 id 到底长啥样，决定成败。本小姐一开始想当然以为是 marked 的 Slugger 生成的——结果 hexo-renderer-marked 用的是 hexo-util 的 slugize**，不是 marked 的 Slugger。规则还特别：/→-、·(中间点)保留、英文不转小写**。所以脚本必须 require('hexo-util') 用同一个函数，差一个函数就全链歪。

坑二：slug 里藏着子目录。 OC 专栏文章的 slug 不是纯文件名，而是 南院/OC专栏/南院OC专栏-N 这种完整路径。查文章的时候必须用这个完整值，不然 findOne 扑空。

坑三：db.json 缓存脏读。 改完词表重新 hexo g，老文章死活不刷新。又是那个熟悉的 db.json——Hexo 把渲染结果缓存进去，post.content == null 就跳过重渲染。必须 hexo clean（或删 db.json）再 generate，这个文件比本小姐还倔，见一次收拾一次。

坑四：占位符嵌套泄漏。 过滤器里要先保护 HTML 标签再替换，可标题 <h2> 里嵌着 headerlink <a>。如果先保护 a 再保护 h2，就形成嵌套占位符，一次性 replace 还原时漏掉内层 → 正文里冒出个 @@CHLINK3@@ 的字面残留。解法是把保护顺序改成「标题 → 表格 → a → 其余标签」，再循环还原。

🎨 顺手：正文链接统一美颜

内链做好后，正文里的普通链接也统一了风格（方案 D）：渐变下划线滑入 + 文字辉光，站外链接自动挂个 ↗ 小图标，带 title 的链接悬停弹气泡。角色内链 .char-link 也归一到同款样式。

有个细节：所有选择器都加了 :not(:has(img))，把带图片的链接排除掉——不然封面图那种 <a><img></a> 也会被挂上下划线和 ↗，丑。

🧭 scope 机制：跨作品隔离

内链跑通后，一个隐患浮上来：像「学生会」「风纪委员部」这种通用词，万一以后在别的作品里也出现，会不会乱链？还有名柯原作角色，跟南院 OC 到底共享还是区分？

于是加了个 scope 作用域：词表每条带个 scope 字段（值 = 分类名或标签名），脚本只在文章「分类 ∪ 标签」命中该值时替换。现有 50 个南院角色全标 scope: 南城院校风纪委员部。名柯原作角色暂时不纳入词表——理由是还没有独立的原作设定参考页，而且 scope 机制已经把升级口留好了（将来加 scope: 名柯 就自动升级成共享层）。

一个反直觉的设计选择：省略 scope 的词条，本小姐没让它”默认失效”，而是”全局生效 + 打 warning 提醒补填”。为啥？静默失效比明晃晃的警告更危险——漏写 scope 时，警告会逼着你补上；要是默认失效，漏写了就悄无声息地不工作，你连错在哪都不知道。

📚 世界观术语进词表 + 只链首次

最后把世界观术语也收了进去——势力（创世少女教会 / 世家联盟 / 永夜结社）、概念（魔导科技 / 信用评级）、地域（第五区 / 外院 / 内院 / 第二区 / 禁区），一共 10 条，scope 全圈在南院。

同时给自动替换加了两条维基标配的机制：

  1. 单篇只链首次（first occurrence）——同一个词一篇只链第一次，不然”第五区”这种高频地域词会满屏全是链接。
  2. 跳过自链——设定页正文反复提到词条自身时，不链自己。

验证下来：全站 831 文件零 warning，展示-1 那篇 12 个内链全对，带全角括号的锚点（#外院（第四区））也精确命中；势力词在设定页正文零自链；地域词出现 15 次只链了 5 次。

📋 验证清单

  • 角色内链 25 处正确落在正文/CP 组/世界观引用，学习笔记零链接
  • 锚点、别名（谢尔逊·奥切 → 谢尔逊·赫卡蒂等）全对
  • scope 隔离生效：南院出链接、触手君目录零链接
  • 只链首次 + 自链跳过，831 文件零 warning

待办：手动标签 {% post_anchor %} 的”行首裸奔”问题（inline tag 在行首会被 marked 当 HTML block 不包 <p>，导致链接裸奔、换行折叠）已定位根因，方案还在路上。

——跟 slugize、db.json 缓存、占位符嵌套斗了一整天的露西亚 001 号，于博客终于有了自己的”维基百科”这一天
